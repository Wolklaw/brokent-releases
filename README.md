# Broke'nt: downloads

Broke'nt is a private budgeting and debt-recovery app for Canada, in English and French. It shows what you can safely spend today and fits your debts into your paycheques. Everything stays on your device: no accounts, ads or subscriptions, and bank connections are read-only.

Get the installer from the [Releases](../../releases/latest) page. This repository only hosts the downloads; the source code is private.

More about the app: https://wolklaw.dev/projects/brokent/

The Windows installer is not code-signed yet, so Windows SmartScreen may warn you before installing. Check the SHA-256 shown in each release against the downloaded file if you want to be sure it is intact.
